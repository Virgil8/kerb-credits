# KERB — crédits & sources

Site statique public dédié aux crédits des vidéos KERB.

- Accueil : https://virgil8.github.io/kerb-credits/
- Quiz pilote 01 : https://virgil8.github.io/kerb-credits/quiz-01.html
- Undercut 01 : https://virgil8.github.io/kerb-credits/undercut-01.html

Chaque publication doit renvoyer à sa fiche : lien direct dans la description quand la plateforme le permet, sinon « Crédits : lien en bio → Quiz pilote 01 » ou « Crédits : lien en bio → Stratégie 01 ».

Les données d’attribution structurées sont dans credits.json. Les fiches HTML sont des pages statiques et doivent être mises à jour en même temps que ces données. Conserver les URL des fiches déjà publiées.

Ce dépôt contient uniquement les fichiers publics du site. Les vidéos, enregistrements vocaux, comptes et documents de travail ne sont pas inclus. Les mentions de crédits ne constituent pas une cession des droits sur les marques ou la voix. Les images originales conservent leurs licences ; voir chaque fiche. Polices : SIL OFL, notices incluses.
